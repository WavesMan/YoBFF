# YoBFF

[简体中文](./README_zh.md) | [English](./README.md)


YoBFF 是一款轻量级、高性能的 BFF (Backend For Frontend) 网关与负载均衡器，专为云原生环境下的集群服务出口场景设计。本项目核心关注点在于运维透明度与安全性，内置管理界面，支持自动化源站防护以及配置的原子化回滚。

## 项目愿景

传统的网关往往将数据面与管理界面分离，或者依赖复杂的外部组件。YoBFF 采用独立二进制文件设计，将高性能的 Go 转发引擎与现代化的 React 管理后端封装在一起。它专门针对源站 IP 泄露这一痛点进行优化，致力于成为云原生应用的安全出口防线。

## 核心能力

### 1. 架构严谨性
- 控制面与数据面在统一生命周期内解耦运行。
- 采用 Go embed 技术嵌入前端静态资源，支持单二进制文件部署。
- 无 CGO 依赖，使用纯 Go 实现的 SQLite 驱动进行状态持久化。
- 基于内存快照的配置原子更新机制，确保热重载期间业务零中断。

### 2. 流量管理与负载均衡
- 基于 Host 的路由转发，支持精确域名与通配符域名匹配。
- 实现了加权轮询 (WRR) 负载均衡算法，具备节点状态感知能力。
- 完整支持 HTTP 与 HTTPS 协议（含 SNI 动态匹配）。
- 支持站点级的主备流量池 (Primary/Fallback) 逻辑，提升服务可用性。

### 3. 自动化源站防护
- 内置 Cloudflare、阿里云 ESA、腾讯云 TEO 插件。
- 自动同步云防护厂商的出口网段 (CIDR)，阻断非法的直接 IP 访问。
- 拦截请求时自动渲染 403 错误页面，并附带请求追踪标识 (Request ID) 以供快速排查。

### 4. 企业级配置管控
- Git 式版本管理：每一次配置变更都会在数据库中存为快照。
- 原子化回滚：支持通过管理界面一键恢复至历史任意配置状态。
- AES-GCM 加密：对 CDN API 密钥等敏感信息进行落库加密，且在 UI 或 API 响应中永久脱敏。
- 审计日志：完整记录所有管理端的操作轨迹。

## 安全实现

- 鉴权机制：管理 API 统一采用基于 Bearer Token 的访问控制。
- 防暴力破解：内置登录防护组件，根据失败次数自动触发验证码校验。
- 接入安全：支持 HSTS 策略，支持受信代理响应头 (X-Forwarded-For) 校验。
- 隐私保护：在差异比对与日志流中自动过滤敏感字段。

## 快速开始

### 环境要求
- Go 1.22 或更高版本
- Node.js (仅限前端开发)

### 后端运行
1. 克隆仓库。
2. 初始化环境：`cp .env.example .env`。
3. 启动网关：
```bash
go run .
```
默认管理地址为：`http://localhost:8080/admin`。

### 前端开发
1. 进入源码目录：
```bash
cd web/source
pnpm install
pnpm dev
```

## 技术规格

- 后端：Go (Golang)
- 前端：React 19, TypeScript, Vite
- 存储：SQLite (modernc.org/sqlite)
- 日志：基于 Uber-Zap 的异步非阻塞管线

## 开发计划 (Roadmap)

以下功能目前处于调研或早期开发阶段：

- 动态服务发现：原生对接 Kubernetes Service API 与 Consul。
- 应用层鉴权插件：支持 JWT 校验与 OIDC 代理。
- 可观测性增强：内置 Prometheus 指标导出器与 Grafana 看板模板。
- 集群配置同步：支持通过 Etcd 实现多个 YoBFF 实例间的配置强一致性。
- 高级 L7 策略：支持声明式的请求重写 (Rewrite) 与熔断机制。
